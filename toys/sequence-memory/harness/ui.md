# UI 原则与设计

> 长什么样、怎么动、怎么回应输入。改外观与交互先改本文再动代码。**具体时长/几何/色值以 `config.js`（MOTION / FEEDBACK / PALETTE / DEPTH）与代码为准**，本文只定意图与契约。核心一句：**画面是一个连续的世界，不是一叠翻页的页面；状态变化发生在玩法物件自己身上，文字只做最少量旁白。**

## 三条原则（拿不准按顺序问）

1. **世界，不是页面。** 局内物件常驻，相位切换是同一世界的状态过渡；整屏重建只发生在进屏与转屏 restart。"换一段文字 + 换一个按钮"式的相位表达是页面思维，打回。
2. **物件先说话，文字后说话。** 状态变化先在玩法物件上被看见（亮起/遮罩/抖动/变色），文字最多补一句短提示。长解释归"玩法"页，局内不承担教学。
3. **每个输入必有回响。** 按下/抬起/点对/点错/相位切换都有视觉 + 听觉反馈，不允许静默的状态变化。

## 两条界面纪律

1. 设置只在开局读一次快照，局内不回读全局设置。
2. **进屏整块重画**（create() 从零构建，转屏 restart 同样）；**局内物件常驻、状态走 tween**，但每次同步从一个 `sync(view)` 入口**全量**由 session 推导目标状态，tween 只把物件动到目标——不允许"只更新我记得的那个对象"。目标状态永远是 session 的纯函数，漏更新在结构上不出现。
- 反馈（波浪/示意/涟漪）是 transient 脉冲，不进目标态：yoyo 落回当前值，玩家提前走时下一次 sync 收掉它们——**状态永远赢**。
- 转屏 restart 免费：常驻物件随场景销毁，create() 从 session 重建，局不丢。重建后首次同步直接落位，不放迟到的入场动画。

## 视觉语言

- 分层沿用 DEPTH：backdrop（夜空+星点+远楼剪影）→ board → fx → hud → overlay。**夜空是活的**：星点固定种子（转屏不换星空）+ alpha 慢眨；背景比视口多铺一圈 overscan。星空要**读得出来**：原 46 颗、α 0.14–0.6 叠近黑底色几乎不可见，顶上读作一片空黑——加到 100 颗，半径与亮度下限各提一档（用户拍板"更明显一点，不需要太复杂"，不加银河光带之类的新层）。
- **远楼剪影 + 偶发流星**（首页视觉补齐，非编号阶段）：夜空加一道地平线——底部紫光之上两层塔楼剪影，**远层浅近层深**（大气透视：远层 `skyNight` α0.6、近层 `skyTop` α0.8，都是夜色不是彩色，图底关系不破"面板半透、背景安静"那条）；近层偏右一座**古代阁楼**（台基 + 四层楼体/平座/飞檐 + 攒尖宝顶，把"更上层楼"这个名字画进背景）：**飞檐翘角用折线逼近**（Phaser Graphics 没有贝塞尔，檐口凹曲线 + 两端上挑取 4 个点，剪影尺寸下读起来就是弯的——直线梯形檐读作通用宝塔，翘角才是"古建"的身份笔）；平座是每层檐下一道比楼体略宽的薄横板，层与层之间才有阁楼的节奏。**塔高 0.32 × 视口高**（从 0.2 抬上来：塔身上半截要高出底部出口那一行，按钮上方 / 按钮缝 / 列侧留白里都看得见；面板主体 α0.50 半透，按钮后面的楼形也透出来——见面板半透那条）；近层楼群高度同步抬到 0.08–0.2。底层一个拱门 + 楼上几粒窗灯（`PALETTE.windowLight` α0.2–0.25，**不眨**——窗灯是静态点缀，不是第二片星空）。剪影与星点同纪律：**固定种子、归一化坐标**（转屏不换地平线），高度从视口高推、底边沉到 overscan 底（纯高度抖动时楼不悬空）。**剪影全场景常驻**（同一个世界的地平线，局内衬在底部动作区后面，静态低饱和不抢呈现）；**流星只给首页**（`objects.backdrop` 收 `opts.meteor`，首页传 true）：上半屏一道暗光斜划（α 峰值 0.3、尾迹分段渐淡、时长约 0.8s、间隔 9–16s 随机），transient 动效不进局内免得扰呈现，其余菜单页也不给。**减少动效时流星整颗不出**（剪影本来就静态，不受影响）。剪影与流星都算背景层，进 backdrop 返回数组（入场动画除外名单）。
- **色块是发光实体按钮不是表格单元格**：常驻圆角块、形状常驻（形状+颜色双冗余），未亮低饱和暗底+弱描边，亮起白色形状+同色柔光+弹一下。四色本身不换。复现棋盘四象限固定，但位置只帮"找到那一块"不构成记忆索引。
- **材质：光源在上方，柔光是加出来的**（上一条那句"发光实体"的画法兑现，三笔，都不是动效——减少动效那条不涉及）。① **柔光一律 `ADD` 混合**：normal 混合下 `glow` 是盖在物件上的一层灰雾，ADD 才是"从物件里透出来的光"（全对粒子早就是 ADD，这一条是把六处 `glow` 拉齐）。② **面板走 `ui.slab`：平填充主体 + 描边，再沿上缘描一道白光、沿下缘描一道暗影**——两笔都是"只描圆角矩形一半轮廓"的部分路径，不是整圈描白（整圈会把下缘也提亮，那就成了玻璃边框而不是"光从上面来"）。平填充 + 1px 描边读起来是"色块"，加这两笔才是"一块被上方光源照着的板子"。用在色块格子、花色 tab、呈现台与 card / chip / button 上；**空台座两笔换边（`sink`）**——它是凹进去的槽不是凸出来的板子；**置灰不给（`flat`）**，材质是给能点的东西的。**菜单构件（card / chip / button）默认态也不给两笔**：平填充 + 弱描边就够，边缘光 / wash / 强调条只留给 hover / 选中——每块板子都带光泽等于每块都在抢注意力，"乱"就是这么来的（首页视觉调整）。色块格子 / 花色 tab / 呈现台是玩法物件，不吃这条收敛，暗底 / 亮起各按原契约给。**不用 `fillGradientStyle` 做主体渐变**：Phaser 3.90 的 WebGL 只在 `fillRect` 上把四角色映到真四角，走 `fillPath` 的形状（圆角矩形就是）被 earcut 切成三角形之后，每个三角形拿到的是 TL / TR / BL 三个角色、按三角形自己的顶点序贴上去（`batchFillPath` 连 BR 都不读），一块板子于是变成按三角形分块的色斑 + 对角接缝；Canvas 渲染器更干脆，`GRADIENT_FILL_STYLE` 整条跳过。**真渐变只用在烤成纹理的地方**（`sky` / `hudBar` 是 image，不经三角化）；也不烤"面板尺寸纹理"——格子 / 台座 / tab / 按钮的边长从 34 到 300 都有，烤纹理要么多份要么被拉伸变形（与牌面走矢量同一条理由）。③ **局内顶条烤一张竖向渐变纹理**（`hudBar`），底缘一段软裙（`CONFIG.HUD_BAR_SKIRT`）渐隐到 α0、软裙起点一道强调细线——读数浮在一层仪表玻璃上；硬底边会把它读成贴上去的挡板。**顶条只在竖屏**：横屏 HUD 在左列、与玩法区并排（4d），全宽顶条会压住玩法区上沿（选牌器的已选序列条首当其冲），而那一侧也没有"从条下面滑出去"的物件。
- **面板半透、背景安静**（首页视觉调整，图底关系）：菜单型构件主体默认 alpha **0.50**（`ui.js` 的 `PANEL_ALPHA`，card / chip / button 三处共用；置灰除外，选中 / hover 态仍 0.96–0.98 坐实）。早先是 ≥0.94 全坐实，远楼剪影长高之后底部出口把楼挡死，**用户拍板让面板透出来**——楼的轮廓透过面板可见（"看到后面大致的内容"）；原拟 0.85，**用户手工调定 0.50，以此为准**。半透是有意为之不是没坐实：透出来的是深色剪影的暗形，浅字深底对比度不掉，选中 / hover 一坐实就把"当前这一块"从半透的底里挑出来；质感来自安静的底 + 清晰的物件，不来自效果叠加，这条不变。显式 `fillAlpha` 的调用方（暂停卡 0.96 坐在 scrim 上、曲线底卡 0.5 等）是各自的例外，不吃这个默认值。首页星空另压暗（`objects.backdrop` 收 `starScale`，首页传 0.8——原 0.55 叠上极暗星点参数后星空几乎不可见，随星点提亮一起放宽；其余场景不传、原样）；标题四字柔光从 α0.34 / 2× 字号收到 α0.2 / 1.7×（ADD 不变，收的是量）；夜空底部 `skyGlow` 那一段 0.4 → 0.3。
- **中央呈现台**：颜色/数字/扑克呈现是屏幕正中一个大符号逐个闪现、位置恒定。台座常驻（暗底圆角方框）当视线锚点；闪现契约与棋盘格子一字不差（**换形态不换节奏**）。**呈现台不接任何输入、无呼吸光**——呼吸是"可以点"的暗示，呈现不给暗示。符号换项换纹理不重建物件。符号多大按类型推，扑克的定案见下条。
- **复现棋盘按类型排、样子同一套规则**：颜色 2×2、位置 3×3、数字 3×4 电话键盘、扑克两步选牌。暗底/亮底/柔光/弹一下各类一致，差的只有排布与标记。**位置类型是唯一在棋盘上呈现的**。
- **位置九格同色、不印数字不印方位**（颜色信息量为零、印字会变成可默念任务）；方位名只在结算诊断行出现。
- **数字电话键盘**（1–9 上三行、0 末行正中、两角留空），十键同色，**数字本身就是常驻标记**；呈现是中央大数字，复现才落键盘。
- **扑克牌面是纸白实体牌**：矢量本体 + 点数/花色白色纹理 tint 成墨色（任意缩放不发糊）。红黑两色墨，**红不用 danger**（那是判定色，牌面红是身份色）。**牌面按牌宽分两档，档由尺寸推不由调用点推**（四处仍是同一份画法）：**full** = 左上 + 右下（旋转 180°，真牌是双头的）角标 + 中央标准点位（A–10 按真实排布，下半区的点倒过来）/ 宫廷窗格（J Q K：窗格 + 大字母 + 上下各一个小花色，不假装画人像）；**mini** = 中央点数 + 中央花色。原先"中央上大点数、下大花色，**不做标准点位、不给四角角标**"那条**已作废**：一对居中的点数 + 花色看着像从真牌上切下来的一个角，不像一张牌。**但 mini 档不跟着升级**——44px 的点数格塞进角标，中央点数就得从 27px 压到 19px，角标在那个尺寸上只有 9px（是噪点不是信息），代价却是复现端的可读性；点数格 / 序列条 / 回放格仍走 mini，小尺寸可读性归 requirements 那条便宜路。**红黑不是唯一通道**：四花色轮廓两两可分。牌背同一条矢量路径不烤纹理。
- **扑克呈现中央翻牌**（牌背→翻正→淡出）；**大牌按可用矩形内接 5:7 吃满**——呈现期选牌器整层隐藏，那张牌是屏幕上唯一的玩法物件，早先"视口短边 × 比例 + 160px 硬顶"是 52 张牌堆时代的遗产、已作废。**不继承选牌器装不下时的缩放**（那是 13 格 + tab 要排得下的事，与呈现的分量无关）。横屏手机在 4d 之后拿得到这个量级：HUD 搬进左列、可用高是视口全高减留白，844×390 拿到 226×316、568×320 与 480×320 拿到 185×259，不再越界；CARD_FIT.min 120 仍是荒谬视口的底，与面板同一条纪律（**宁可溢出也不缩到下限以下**）。**复现两步选牌**：当前花色 13 点数格（2 行 7+6 迷你牌面）在上，4 花色 tab（图形+已选计数）钉底。**tab 挪底是用户拍板的手感调整**（原在顶部）：随机牌序相邻两张约 3/4 概率不同花色，切 tab 几乎每张牌都要来一次——它是与点数格同频的输入层不是低频导航，放底下离拇指更近；认下的代价是点数格整体上移、视线先落点数格再折回底下选花色。点花色导航、点点数格判定。选过压暗置灰不可再选（仍认得出牌面）；点错盖危险色但牌面仍看得清。**三种高亮不能撞**：tab"当前"态（紫描边+顶部指示条，非颜色通道；tab 在底、指示条翻到顶缘指向点数格）/ 点数格"已选"压暗 / "点错"危险色。
- **已选序列条**：选牌器顶部（点数格上方）横排自己点过的牌，与点数格共用列栅格。承担两件事：置灰总览、全对波浪载体（按点选顺序扫这条不扫面板）。**预留两行、带子下沿钉住**（第 8 张往上长一行，tab 与点数格不跳位；超两行只留最近 14 张）。**不接输入、无呼吸光**（只读）；新一张淡入+弹一下；判定已定后仍留着；**牌面不带判定色**（错成哪张由点数格危险覆盖说）。
- 玩法区**不出现卡片/描边面板/徽章**（那些是菜单屏构件）；局内只有格子、遮罩、HUD 顶条 + 裸文字与进度点。遮罩是半透明 scrim + 一行小字，不是换一屏。
- 字体：系统字体，层级靠字重字号；**局内正文不超过一行**；尺寸一律从 layout 推不写死像素。

## 玩家屏幕不出现开发期文字

阶段号/roadmap 脚注/"阶段 N 接入"全部退出屏幕。置灰只剩 `pending`（"未开放"，只用于未开放的类型行——记录 / 设置入口都已转活）；`locked` 作废。**没开放的玩法档压根不画**。无历史记录 meta 显示"–"不解释。

## 局内构成

竖屏自上而下：HUD 顶条（类型·模式·长度大字·进度点·暂停，**底下垫一层渐变顶条纹理 + 软裙**，见视觉语言材质那条；横屏不给）→ 一行短提示 → 玩法区（居中吃剩余空间，**不小于可用短边 0.8**，面板是主角）→ 底部进度读数+动作按钮（钉底）。**横屏：HUD 搬进左列**（4d 定案：两行顶条在横屏吃掉一百多 px 高度，选牌器最小框高 276 在 320–390 高的横屏上底行被裁掉半行——搬进左列后玩法区吃满上下留白之间的全高，844×390 / 568×320 / 480×320 底行零裁切）。左列自上而下：HUD 三行（读数+暂停 / 长度大字+进度点 / 关次+计数）→ 短提示 → 底部读数+动作按钮钉底；玩法区右半居中。**左列宽 = 面板左沿再留一道缝**（下限只挡荒谬视口；**窄于 480 的横屏保证不了不重叠**——选牌器 min 332 是触控硬底，宁可溢出不缩）。同构件换排布不是缩小版。**窄左列截断纪律**（与读数截断同源）：读数可缩到只剩类型一段；进度点放不下就藏（计数保留）；关次与计数放不下同一行时关次让位（关次在暂停与结算里仍有）。

**HUD 的速度读数是局内活值，不是开局快照**：休闲跨过里程碑之后它跟着变小，这本身就是"提速"的可见证据（冲榜与挑战不提速，读数全程不动）。纪律 1 管的是**设置**（开局读一次、局内不回读），里程碑与长度同类，是局内状态，由 session 推导。**结算的组合读数仍显示开局那一档**（组合键 = 类型×模式×方向×速度档，那是记录身份），所以同一局 HUD 与结算的 ms 数可以不同——这是有意的，不要"修好"它。

**进度点可关**（4c，设置页"进度点"开关）：关时 HUD 只砍圆点（含点错的红点），"已输入 n/m"计数保留——文字读数不是点。错处的表达不丢：底部"错在第 x 位" + 危险色 / 抖动 / 低鸣照旧。开关读开局快照（纪律 1），局内不回读。

**方向读数是倒序局防"忘了这是倒序"的主要保险**：类型·模式·方向·速度四段常驻，窄屏截断先砍速度、再砍方向——方向比速度多留一手，倒序局宁可少看 ms 也要看得见"倒序"；横屏窄左列一路砍到只剩类型是 4d 的取舍（方向还有 recall 短提示"倒着点回来"兜底）。呈现端不因方向变（仍正序闪现），方向的表达只在读数与 recall 短提示两处，不加新物件。

**相位操作权限（局内全部交互面）**：

| 相位 | 玩家能做 | 入口 |
|---|---|---|
| 准备/呈现 | 只看，只能暂停 | HUD 暂停（chrome 不算玩法输入） |
| 隐藏 | 决定何时开始 | "开始复现"按钮 |
| 复现 | 点色块即点即判 | 色块本身；进度点只读 |
| 全对/点错 | 等自动去向或手动提前走 | 次级小按钮（主角是反馈动画） |

**短提示文案**：lead 准备 / present 记住顺序 / hidden 该你了 / recall 按顺序点回来（**倒序局改"倒着点回来"**）/ cleared 全对，长度 +1 / failed 点错了。长度 n 不进句子（HUD 已表达）；规则解释只在"玩法"页。**休闲跨过里程碑的那一关，lead 改说"提速"**——一关只说一次，第一项亮起来就回到正常提示；它说的是"发生了什么"，不是规则解释。

**复现契约**：全部节奏（亮起/熄灭余晖/遮罩/呼吸光/逐格示意/波浪/按下缩放/点错危险色）一处实现，**不因类型也不因呈现形态而变**。判据：切到另一类型复现节奏反馈一字不差；呈现形态本该不同（玩法差异）。触控 ≥44px（最小边长随列数走，写在 BOARDS）；外框是主角、不一定正方形（高由 measure 一处算）；类型分支只准出现在画法与分派处，场景与状态机不认类型。

## 动效与反馈契约

时长是设计值，实现进 CONFIG。事件→效果：

| 事件 | 视觉 | 声音 |
|---|---|---|
| 呈现亮起 | 柔光淡入+弹一下+标记转白（位置在格子、其余在呈现台） | 短促音（音调关时中性音） |
| 呈现熄灭 | 柔光淡出留余晖，回暗底/空台座，不瞬灭 | 无 |
| 呈现翻牌（扑克） | 牌背→scaleX 挤压换面→翻正→淡出 | 同亮起 |
| 呈现→隐藏 | 位置：遮罩淡入压暗；其余：呈现台淡出+盖遮罩的棋盘淡入（交叉淡入非硬切） | 低落音 |
| 隐藏→复现 | 遮罩淡出，格子依次轻呼吸示意可点 | 上行短音 |
| 切花色 tab | tab 高亮换过去，点数格整组换面，已选保持置灰 | UI 点击 |
| 按下 | 缩到 0.94 | 无（声音在抬起） |
| 点对 | 那一格亮+涟漪扩散+进度点填一格；扑克序列条多一张 | 清脆短音（颜色音调开时按色定音高） |
| 点错 | 危险色+玩法区左右抖+全屏红闪+hit stop | 低鸣 |
| 全对 | 波浪亮一遍（扑克扫序列条）+长度大字滚动+小粒子爆发 | 上行琶音 |
| 跨里程碑提速（休闲） | 短提示说一次"提速"+HUD 的 ms 读数变小 | 上行两音，比"开始复现"更亮（是不同的事件，不复用同一个音） |
| 进局/切换 | fadeTo；进局面板缩放入场 | 无 |
| 结算大字 | 数字滚动 | 新纪录庆祝音（5a） |

两条约束：**hit stop 用节拍延迟**（fail 节拍推迟，不引新定时器）；抖动的实现坑见 architecture。复现待命态格子极轻呼吸光；呈现阶段无呼吸（呈现台同样没有）。

## 声音

基础音：UI 点击 / 呈现亮起 / 遮罩落下 / 开始复现 / 点对 / 点错 / 全对 / 里程碑提速；庆祝音随 5a。iOS 首次手势解锁 AudioContext。

**两个开关（4a 落地）**：通用音效（默认开）管全部声音；颜色音调（默认关）只管颜色类型的**呈现亮起与点对**——开后一色一个固定音高（config.COLOR_TONES，与 COLORS 同序，四音要能哼出来），关时这两处回落各自的中性音，其余声音不受它影响。点对也按色定音高是刻意的：复现端跟着哼是第二条语音回路，只给呈现端定音高就只剩半条。开关是全局偏好：本地持久化（systems/Prefs，读值只认布尔、写不进退回内存），**开局读进快照、局内不回读**（纪律 1），所以局中改不了、下一局才生效。

**开关入口在设置页**（4c 起；4a 曾暂住首页，4c 整块搬走）：开 / 关是行按钮标签里的文字标记（"音效：开"），不只靠选中态（非颜色通道）；点一下整块重画设置页，与首页换档同一条纪律。**打开音调开关当场把四色四音高完整预览一遍**——开关的回响就是它本身的声音，玩家不用开一局才知道这四个音是什么；音效关着时预览同样被挡住。

## 菜单型屏幕

card/chip/badge/button 只在这类屏幕出现。

- **button 标签居中当且仅当没有右侧读数**（meta / hint 都没有）：纯动作按钮（首页三出口 / 暂停三出口 / 局内"开始复现""下一关" / 各页"返回首页"）文字居中——左对齐加右端留白会让每枚按钮的视觉重心偏左，整排看着像没居中（人点发现；整排位置本身是居中的，量过）。带 meta 的列表行（首页类型行 / 结算宽列出口）保持左标签 + 右读数：两端对齐是列表的语言，居中是动作的语言。**唯一例外：设置页行按钮显式 `align: 'left'`**——状态写在标签里（"音效：开"）、没有 meta，但整行读的是"一行偏好"不是"一个动作"，与 shooting-stars 设置面板同一种列表语言。

- **首页**（开局前唯一一屏）：四色标题弹入；玩法档一行**等宽三段**（休闲 / 冲榜 / 挑战，默认档排最左）；四档类型行 meta 只显"最高 n"或"–"；**点类型行直接开局**。换档整块重画首页（meta 与读数跟着变）；点类型即开局无确认步（误触代价一次点击）；规则解释不在首页。
  - **横屏：左列品牌区 + 出口钉底，右列玩法区**（4d 定案：320 高的横屏右列装不下玩法档行 + 四行类型 + 出口，出口搬去左列底部，与设置页同一种排布）。**短横屏压缩**（右列装不下正常排布时）：类型行不画"点一种类型就开局"标签、行缝收紧——四行 44px 与玩法档胶囊是触控下限，不可再压。标题字号同时受左列宽约束（四个字加字距放得下），窄列不溢进右列。
  - **玩法档胶囊与出口按钮 ≥44px 高**（4d 补齐：此前手机上只有 33 / 40，与局内同一条触控纪律）。窄列出口的右侧读数（"未开放"）放不下时让位，置灰仍由暗底 + 弱描边表达。
  - **玩法档一行是等宽三段，不是三枚跟着文字走的胶囊**（视觉调整，非编号阶段）：档名只有两个字，`ui.chip` 的宽度跟着文字走时量出来 49px，而触控下限把高度顶到 44——宽高比 1.11，三枚排一起像三个圆点而不是一组选项，行尾还空着 130 多 px。改成**按可用列宽三等分**（390×844 竖屏每段 93、320×568 竖屏 74、844×390 横屏右列 120），余数给最右一段，行尾与下面四行类型行齐平。**圆角仍是 `height / 2`**：chip（选项）与 button（动作 / 出口，radius ≤14）靠圆角分开形状语言，改直角会让首页"选一个档"与"点一行直接开局"长得一样；等宽已经把"圆点"的观感去掉了，人点之后仍嫌圆再把这一行的 radius 收到 10–14（局部改动，不动其他四处 chip）。
  - **段宽不足 72 就砍掉"玩法"行标签、三段吃满整列**（568×320 横屏右列 261 → 砍标签后每段 83、480×320 右列 222 → 70）：72 与底部三枚出口"每枚 ≥72 才给 18 内扣"是同一个数。砍标签有先例（记录页类型胶囊、"玩法"页四页胶囊都不加行标签，理由都是"白吃一行"），这里砍的是行内前缀——档名本身就是玩法档的名字，下面那行读数还写着"冲榜 · 正序 · 每项 700ms / 每关全新序列"，"这一行在选什么"不靠那两个字也读得出来。判据按量出来的段宽推、不写视口阈值（与短横屏压缩同一条）。
  - **唯一例外：玩法档读数下面那一句，描述生成方式与方向**（休闲"重播旧序列，末尾多一项" / 冲榜"每关全新序列" / 挑战"每关全新序列，倒着点回来"）。档名本身不传达差别，而承接长解释的"玩法"页是常驻入口、不强制读，玩家仍可能盲选——选错档产生的记录还不可比。两模式判定相同（即点即判），所以这一句不提判定；方向是"玩什么"不是判定，挑战那句带上它。**读数顶对齐**（origin 0.5,0）：此前居中对齐让两行读数的上半截骑进胶囊行缝、压住胶囊下沿（截图核实过的真重叠）；顶对齐之后行缝才真的是缝。
  - **声音行已搬走**（4c）：音效 / 音调两枚胶囊收进设置页，首页不再占这一行；底部出口 记录 / 设置 / 玩法 三枚按钮（第三枚随 7 补齐），三个入口都通着真实场景。**窄列 padX 收到 8**：480×320 横屏左列只有 192px，三枚各 58px，"玩法"两个字 14px 约 29px 宽，默认 18 的内扣放不下（58 − 36 = 22）；每枚 ≥72px 时恢复 18。
- **设置页**（4c 落地，只放全局偏好，不放玩法档——"玩什么"在首页；视觉调整参考 shooting-stars 设置面板，非编号阶段）：四行，每行 = 一个吃满列宽的行构件 + 下方一句小字说明。**音效 / 音调 / 进度点是整行按钮**（`ui.button`，`align: 'left'`），状态写进标签（"音效：开"，状态即文案，非颜色通道）——旧的小胶囊"开 / 关"作废，整行比胶囊大气，点击目标也从一枚胶囊变成整行。**起始长度是 − / + 步进行**（与 shooting-stars 音量行同款）：行底一块整宽 slab（`ui.card` 不可选，radius 14 与按钮同语言），两端各一枚方形按钮（边长 = 行高 − 12，仍 ≥44 触控下限），中央读数"起始长度 n"；**步进仍走 START_LENGTHS 离散三档 2 / 3 / 4**——上限低于第一个里程碑 5 的定案不动，步进器只是换画法不是放开范围；到边界那一端置灰（flat 不接指针，默认 2 时减号一开始就是灰的）。行高 = max（触控 + 12, unit × 2.4)，说明行在窄列砍掉（width < 300，与首页类型行 verbose 同一条取舍）。点任何一下整块重画（纪律 2）；打开音调当场预览四音（见"声音"节）。竖屏出口"返回首页"钉底；横屏同构件换排布：左列标题 + 总说明 + 返回钉底，右列四行。总说明一句"全局偏好 · 下一局生效"——局内没有入口，"局中改不了"不用解释。Esc 返回是桌面增强不是前提。
- **结算**（大字长度是绝对主角，从"报告"改"成绩"）：徽标+组合读数（"每项 Nms"不带档名）→ 大字+数字滚动 → 同组合历史最高（或 –）→ **参照一行 + 近似标注（5d）** → 指标行（停在第 n 关·该关长度·错在第 x 位·已输入 k/m）→ **诊断一行**（"第 x 位：该点…你点了…"）→ 逐位回放（标题只留"逐位对照"+三态图例）→ 免责底注一行 → 两出口。**规则解释归"玩法"页、物件说过的话文字不再说**；信息一条不砍，砍的只是重复句子。**横屏长序列回放有高度预算**（4d）：装不下就缩格子边长（下限 18px，位次数字 ≥22px 才给），不把图例与免责底注推出屏幕；竖屏无预算、行为不变。窄列出口按钮的右侧读数（"同设置"/"回首页"）放不下时让位（与首页同一条截断纪律）。
  - **参照一行（5d，gameplay 反馈 ④）**：两行小字，第一行是参照本身（`常模参照 · 这一局约在第 P 百分位` 或 `历史参照 · 这一局在最近 N 局里排第 K 好`），第二行是它的近似标注（10px，比第一行更淡——标注是给愿意读的人读的，不该与数据抢视觉重量）。**竖屏排在"同组合历史最高"下面**（gameplay 的 ③ → ④ 顺序）；**横屏归右列、排在诊断之后**：左列在最紧的两档横屏（480×320 / 568×320）上只剩二十几 px 余量，多两行会压到出口按钮上，而右列本来就有回放的高度预算机制，多两行只是格子小一号。**三种情况整块不画**：0 分局（没有成绩可比）、破纪录且无常模（"第 1 好"与新纪录徽标、历史最高那行说的是同一件事）、只有一局且无常模（"第 1 好"不是信息）。**标注跟着参照走**：没有参照行就没有标注行，颜色 / 扑克 / 休闲的结算屏一个字都不提常模。
- **回放格符号按类型画**（颜色形状/位置迷你九宫格只亮对应格/数字本身/扑克迷你牌面），**回放要能不靠颜色读懂**；三态画法（素格 / 整格描危险色 + 右上角折角 / 破折号）不因类型而变；诊断符号名只此一处（symbolName）。
- **暂停**：scrim + 三出口。
- **记录页**（5b 落地，5c 加曲线）：**按类型分页**（四枚类型胶囊 = 四页，类型之间永不同屏比较）+ **每组合一张卡**（休闲 / 冲榜 / 挑战，各读自己的组合键，"互不串键"在画面上直接可见）。**冲榜档的卡按 tie-break 排**（最高 desc → 总错次 asc → 平均复现用时 asc，判据见 gameplay），**休闲卡在分隔线下面单独一栏、不参与那个顺序**；分隔线之外不加组标题——卡里的档名已经写了"休闲"，再写一行是重复句子。**不写"排行榜"三个字、不给名次数字**：单人本地榜，说"排行"是过头话，顺序本身就说了话。
  - **一张卡只有两行**：第一行 组合读数（档名 · 方向 · 每项 Nms，与首页 / 结算同一口径）在左、历史最高的大数字带"最高"小标在右；第二行 达成日期 · 总错次 · 平均复现用时 · **常模约在第 P 百分位（5d，只有冲榜档的 数字 / 位置 有这一句）**。无记录的档：数字位显示"–"、第二行整行不画（不解释为什么没有）；打出过 0 分的档仍是"–"，但总错次与平均复现照给（与 `bestOf` 同一份口径）。
  - **常模那一句挂在第二行末尾，不新开一行**（5d）：① **卡仍然是两行**——5b 那条不变量没破，两行的分工也没变（第一行 = 这一档是什么 + 打出过多少，第二行 = 小字读数），常模句与达成日期 / 总错次 / 平均复现是同一类东西（每组合一行小字），不该自己占一行；② **便宜一点也更可退**：新开一行是每张卡固定 +19px，挂在行里只在把第二行挤成第三行时 +15px，而且阶梯砍它的时候是缩短一个字符串、第二行立刻收回去。最紧的横屏右列（480×320 只有 222px 宽、预算 223）三张卡按最小排布就要 211，两种做法在那一档都会被阶梯砍掉。**卡上不重复"最高 N 项"**——大数字就在同一张卡的第一行，"按最好一局算偏高"那句实话在页脚。
  - **卡可选（5c）**：点一张卡 = 把曲线换成这一档的。选中态是描边加重 + **左侧一条强调条**（与 `ui.button` 的 active 条同一套语言，不只靠颜色），hover 重画描边，抬起响一下 UI 音；换卡整块重画（纪律 2）。5b 那句"卡不接输入"就此作废——当时不做是因为点了没反应比置灰更像 bug，5c 给了它反应。**默认选中草稿那一档**（下一局要玩的那一档），选中的档跨类型保留（三个档每个类型都有）。键盘选择留给 8d（与类型胶囊一致，8d 前纯指针可走通）。
  - **曲线块（5c，`objects/Chart.js`，手绘折线不引图表库）**：画选中那张卡的最近 `HISTORY_LIMIT` 局 + **历史最高虚线参考线**（虚线 + "最高 N" 标签，与实线曲线的差别在虚实与标签上，不只靠颜色）。标题左"最近 20 局 · **本游戏成绩**"（措辞红线要的那句标注长在图上，不只长在页脚）、右组合读数；窄列放不下时**读数让位**（与首页 / 结算窄列右侧读数同一条截断纪律）。**横轴是固定的 20 个槽位、从左端起**：不满 20 局时曲线往右长，满 20 之后每来一局整条左移一格；比例尺不随局数变，两次打开页面看到的斜率是同一个斜率，右边空出来的地方是还没打的局。**纵轴 0 起**，顶就是"最近局里的最高 / 历史最高"较大者**本身**——不向上取整：顶上那个数字得是玩家真打出过的成绩，取整会画出一个谁都没打到过的数当参照；中间刻度按 1 / 2 / 5 的十倍进位挑，一格不足 14px 时只留两端。**点必画**：只有一局时折线一段都没有，那个点就是"你打过一局"的全部证据；最近一局大一号。**这一档一局都没有**：标题照画（说明这块是什么）、图位一行"这一档还没有记录"——只说状态不解释为什么没有，与卡片"–"同一条纪律。**曲线不进结算屏**（理由见 gameplay 反馈节）。
  - **装不下预算时按顺序降级，不做第二套卡片排布**（同结算回放那条高度预算的思路）：曲线的高度**先**从预算里划出来（块高 = 内扣 ×2 + 标题行 + 缝 + 图位；图位目标 `unit × 2.6`、夹在 30–96，口径在 `objects.chartFit`，与画法共用一份；**划的时候按"三级旋钮全关"量卡片的最小总高**），卡片拿剩下的跑阶梯——先砍达成日期（`width < 300` 的窄列一开始就不给，与首页类型行 verbose / 设置页说明行同一个阈值），再把数字字号缩到 18px 下限（与结算回放格同一条下限），**再砍常模那一句（5d，第三级）**，三级都到底还留不出曲线的最小块高才砍曲线。顺序不能反：卡片先吃满、曲线拿剩的，小屏上明明降一级字号就放得下的曲线就会被砍掉。**页脚与卡片一张都不砍**——gameplay 措辞红线点名"练习效应 / 平台期"那句实话写在记录页脚，5d 的常模标注也挂在页脚（见下条）。文字先建后量、降级只 setText / setFontSize 不重建物件，所以卡高是量出来的不是估出来的。
  - **常模标注挂在页脚、跟着"这一页有没有常模"走，不跟着降级阶梯走**（5d）：数字 / 位置两页的页脚多一句（近似 + 常模听觉 / 本作视觉 + 按最好一局算偏高），颜色 / 扑克两页一个字不提。不能反过来（"卡上还留着常模句才给标注"）——阶梯要先量页脚的高度才知道卡片有多少预算，页脚又要等阶梯的结果，这是个循环。**标注与页脚原句合成一个文字物件**：页脚本来就是量出来的，多一句话在竖屏只是多一行，在横屏左列会从曲线预算里扣（按视口算过：480×320 曲线从 88 降到 87、320×568 从 88 降到 78，都还在最小块高之上，一块图都没丢）。窄列（`width < 300`）换短版，与卡片的达成日期、首页类型行 verbose 同一个阈值。
  - **类型胶囊排在内容列（横屏是右列）不加"类型"行标签**，padX 收到 10：480×320 横屏右列只有 222px，四枚 ≥44 的胶囊按默认 padX 要 214px、差一点就换行，换行再吃 50px 高度会把卡片压到字号下限以下；收到 10 是 206px。换行逻辑仍留着当兜底（按 chip.width 累加测）。
  - **当前类型与选中的档存场景实例字段，不传 data、也不回写 `Setup.draft`**（理由见 architecture 已知坑）。认下的代价：离开记录页再进来停在上次看的那一类型、那一张卡，不回到草稿那一份。
  - 横屏同构件换排布：左列标题 + 一句总说明（窄列砍成半句）+ **曲线** + 页脚 + 返回钉底，右列类型胶囊 + 三张卡（与设置页、首页同一种排布）。**曲线在左列不在右列**：480×320 的右列只有 222px 宽，三张卡按最小排布就把预算吃完了（844×390 的右列预算 281、最小排布也要 230 上下），放右列等于在最紧的那几档视口上没有曲线。左列宽 = 192（480×320）/ 231（568×320）/ 348（844×390），高是总说明与页脚之间剩下的那段、封顶到目标块高（`unit` 18 → 88、22 → 103、44 → 172）；竖屏排在三张卡下面，宽 = 内容列宽（390×844 是 336、320×568 是 276）。左列的曲线预算不足最小块高时整块不画。
- **"玩法"页**（7 落地，静态规则页；原教学关改判取消，理由见 requirements）：承接全部规则长解释——三段相位、点错即终、得分口径、休闲累积追加与里程碑提速、倒序、扑克两步选牌与选过置灰、不限时、暂停与放弃、本地记录——局内短提示与结算不再重复。**四枚胶囊分页：规则 / 玩法档 / 类型 / 记录**（与记录页类型分页同一种构件，四类型 × 两模式 × 两方向的规则分布在这四页里，纯指针每页可达）。每页若干节"小标题 + 一段正文"，左对齐；**正文先建后量，装不下预算按顺序降级：字号 12→11 → 收行距 → 收节距 → 收标题缝**，不做第二套排布，标准视口（含 480×320 横屏）不裁切。
  - 横屏同构件换排布：左列标题 + 总说明（窄列砍短版）+ 返回钉底，右列胶囊 + 正文（与设置页 / 记录页同一种排布）。**左列取 0.38**（其余菜单页 0.44）：这一页左列只有标题与返回，没有曲线也没有偏好行，收窄让宽给正文——480×320 的右列从 222 变 248，正文行数少一档。胶囊 padX 收 8：四枚 ≥44 的胶囊一行 206px 放得下，换行会再吃 50px 高度把正文压到下限以下。
  - 当前页存场景实例字段，不传 data（与记录页同一条理由：转屏 restart 重放 data 会冲掉玩家后来点的页）。**无已读标记、无首次强制拦截**；是否首次自动打开一次留给人点决定（requirements #9），未实现。Esc 返回是桌面增强不是前提。

## 无障碍与降级

- **减少动效**：跟随系统 `prefers-reduced-motion`，**不进设置页、不持久化**（是系统偏好不是玩家偏好；开关在物件构建时读一次，场景 create / 转屏 restart 会重读，等于免费跟随系统切换，与"设置只在开局读一次快照"不冲突）。砍掉的是装饰性运动：抖动 / 粒子 / 涟漪 / 弹跳（亮起弹一下、序列条弹入、按钮 hover 浮动）/ 呼吸光 / 全屏红闪 / 进场弹入与上浮 / 大字数字滚动（直接落值）/ 星空慢眨与标题浮动（常驻装饰，静止画一次）/ 切花色的挤压回响（牌面内容本就立刻换），以及波浪与逐格示意的**行进感**（降级成同时亮，不是不亮——那两下说的是"全对了""可以点了"，是信息）。**保留亮起 / 熄灭余晖 / 遮罩 / 变色 / 翻牌 / 按下缩放等信息性动画**（砍了游戏没法玩）。hit stop 是节拍延迟不是动画，照旧；声音不受影响。splash 的 CSS 动画由同名媒体查询就地关掉。
- **色觉友好靠常驻冗余，不设开关**（4b 定案，理由见 requirements.md）：形状常驻即唯一非颜色身份通道（**不做位置标记、也不在色块上印文字**——印了会把视觉身份任务降级成可默念的命名任务）；所有反馈有非颜色通道；结算三态不只靠颜色（未输入 = 破折号、错 = 右上角折角 + "期望 / 输入"两行的符号差）；扑克靠四花色轮廓、tab"当前"态另有顶部指示条、已选是压暗不是换色。**新增任何"只靠颜色"的表达都算违约**：同时给形状 / 文字 / 粗细或位置差才算数。
- **触控 ≥44px**：所有按钮/色块/tab/点数格/序列条槽位以此为下限，**扑克无豁免**。首页玩法档胶囊与出口、设置行按钮与步进按钮、暂停三出口都在内（4d 逐屏核过，补齐了首页两处 33 / 40 的旧值）。
