# UI 原则与设计

> 长什么样、怎么动、怎么回应输入。改外观与交互先改本文再动代码。**具体时长 / 几何 / 色值以 `config.js`（PALETTE / DEPTH / 各特效表）与代码为准**，本文只定意图与契约。核心一句：**命中反馈是全项目最该投入的地方——"打中"必须在感官上响亮；背景是活的黄昏夜空，不是贴图。**

## 视觉语言

- **黄昏 → 夜空**，不用纯黑：顶部夜、地平线暖橘，保留暖色不拒人。背景分层（天空 / 星点 / 装饰流星 / 远山 / 树线 / 地平线光带），星点密度与天空紫调随连击提升，地平线随最低星逼近脉冲变亮——氛围随强度变化。
- **星星是程序化烤纹理，零图片资源**：圆润五角星，"外圈饱和可 tint + 白芯独立一层"——tint 是逐像素相乘，主体渐变做不出白芯，深色星 + 深色字母读不清是硬伤。字母深色 + 白描边始终正立（自转只转星体不转容器）。下落贴图超采样烤、显示缩回，任何 DPR 只缩不放。
- **数字走等宽字体，字母走正文字体**（8 易混字形）：正文字体里 `0` 与 `o` 只差高度——34px 下实测墨迹 25×19 vs 18×18，形状都是同粗细的圆环；`1/l/i`、`2/z`、`5/s`、`6/b`、`9/g/q` 同理。**尺寸级线索**在 72px 星体 + 白芯 + 白描边 + 下落运动里读不出来，玩家只能靠"哪个更高"猜。等宽字体的斜杠零、带底横的 `1` 是**类别级线索**，不用比大小就分得出。星体字母与命中上飘字母必须同一份字形（否则炸开那一下换脸）。菜单底部的字母池预览行本来就是等宽渲染，这条让局内与菜单对上——"等宽 = 键位"。代价是字形家族依赖系统字体：`CONFIG.MONO` 那串栈 macOS 落 Menlo、Windows 落 Consolas（都是斜杠零），**换平台要点一眼 `0` 里有没有那道斜杠**；没有就说明该平台 generic monospace 不给斜杠零，得升级成自己烤字形纹理。符号（`.` `,` `'` 一类）不在此列：它们的问题是太小不是混淆，单独议。
- **类型靠形状辨识，不靠颜色**（色觉友好）：金色星四芒、冰晶六角 + 棱面短线、黑洞吸积盘 + 旋臂 + 光子环（颜色烤死不 tint）、双星两颗小星 + 连线 + 指向下一颗的箭头。Canvas 渲染器忽略 tint 时，形状是唯一还分得出类型的通道。
- **双星的顺序靠大小读，不靠颜色也不靠文字**（线连双星是键序判定的两键特例，**仅标准方案使用**，9d；单元方案用下面那套单体造型，不挂线连）：大那颗是现在要敲的，小那颗是下一颗，连线末端的箭头指向下一颗（颜色沿用普通星那五色，一对两颗同色才读成一个整体）。首颗敲掉后**变暗 + 连线缩短 + 第二颗放大到同级**，一段短过渡，在 step 里按闭式缓动推不挂 Tween。字母跟着节点同比缩（只缩不放），所以双星的字母比常规星小一档——这是"一对"付的可读性代价，待敲那颗始终是这对里大的那档。
- **单体序列星（9e）：进度点在上方那条最宽带、显示面在下方**，星体从 72 长到 **96**（×4/3，剪影自相似——"看上去还是同一颗星，只是大一档"）。这不是审美选择而是几何裁决：五角星（外尖 26 / 内凹 13）的实心区最宽处在 y ≈ −8（半宽 ±24.7），y=+8 只剩 ±13.1、y=+13 收成一点（底部那个 V 形缺口），**竖向实心带总共 23.5px**；Lv5 的汉字面（墨迹半高 11.2）+ 净空 + 一排点约 27px，72 装不下，而且没有任何排布能救——穷举过，72px 里能塞进去的最大汉字是 17px，等于把 gameplay.md 的高速档可读性补偿整条撤掉。**坠毁判定仍是圆心过线**（与常规星同一份 `star.y > HORIZON_Y`，不按星体尺寸补偿）：反应窗口因此一字不变，代价是大星体的下尖比常规星早 12px 压进地平线亮带——那是"这颗更大"的自然读数，不要为了对齐下尖去改判定线。
- **放大走 `setDisplaySize`，不走星位容器 scale**：`display.js` 的 `rescaleText` 会递归把每个 Text 的 resolution 强设回 `RENDER_SCALE`，所以"容器放大 + resolution 补偿"这条路在窗口拖到另一块 DPR 屏那一刻被静默清零、字立刻糊。改显示尺寸则星位容器 scale 恒精确落在 1、字号是世界 px 栅格化 1:1，贴图仍只缩不放（starHi 源 216 ≥ 96 × 弹入峰值 1.08 × 闪白峰值 1.35）。
- **进度点靠亮暗、也靠大小**（色觉友好同一条纪律）：暗点是深色小点（α0.55、半径 ×0.8），亮点是白点大一档 + **1px 深色描边**——亮点有一半概率落在白芯上，没描边就溶掉。**点不染星色**（星色是类型 / 身份通道）、**不用金**（金是金色星的身份色）。点是 Graphics 挂在星位容器里：跟星体同比缩放、**不跟星体贴图自转**（自转只作用于贴图与四芒），只在生成与推进时重画，绝不每帧。
- **序列星可读性红线（原未决 #8 的定案）**：最小面字号 **18px**（世界坐标）；面字号随档位 fontSize 走（**×0.66**——汉字按面积读，把 34px 的拉丁字号照抄到汉字上会捅出白芯）；**星体尺寸恒定，不随键序长度逐星变化**——键序长度只决定点的个数，点距 / 点径恒定、整排居中，于是 2 键星的点是 6 键星的前缀，星体大小不会变成"这颗有几键"的读数。**多音字（9g）不改这套几何**：收字只收各读音等长的，所以"这个字有几键"仍然唯一、点数照旧 = 该字键数，多音字与单音字画出来一模一样（取舍全文见 gameplay.md 多音字节）。判定圈（白 / 暖橘）跟着星体同比长，否则 96 的星尖离 36 的圈只剩 1.3px、白圈贴在星尖上。
- **双拼方案（9f）复用同一套单体序列星造型，不另立造型**：星面仍是单格汉字、星体仍 96，双拼恒 2 键所以进度点恒 2 格（正是 6 键星点排的前缀）。**造型定案：用汉字面而非音节面**——音节面是拉丁多格，6 格在 96 星体上撞 18px 红线（`unitFaceSize(level, 6)` 如实报塞不下），升级星体到 ~160+ 才塞得下、会牵动一串已验收几何；汉字面单格逐字复用上面那套已验收造型，零几何风险（取舍全文见 gameplay.md 双拼方案节）。
- **光尾与白芯在 96 星体上是记在案的例外**：光尾残影与生命图标共用那张 72 源纹理，单元星因此拖一条比星体窄一档的尾（尾本来 0.85→0.5 渐缩、"大半藏在星体背后"是既有预期）；白芯是 32 源按需放大到 42.7——它是软径向渐变，没有硬边可糊。两者都不重烤：`star` 有 6 个消费点、`starCore` 有 5 个，漏一个就在已验收的画面上静默大三倍。判定圈那张 `ring` **重烤到 128**（圈半径 36→48）：它是 2.5px 硬边、最经不起放大，而且只有一个消费点。
- **光尾是流星的灵魂**：同色残影渐隐，长度随速度自然变长；连击 ≥3× 加亮 + 白芯；速度越快拖得越密。慢速档尾大半藏在星体背后是预期。**双星只有一条**（从两颗中间发）：各拖一条会把残影池顶穿，而居中那条恰好强化"这是一个整体"。
- **装饰流星与可交互星必须五条差异全占**：更暗、更小、更快（本档星速 ×2）、斜向、无字母——玩家不会想去敲背景。
- **两种脉冲描边语义不撞**：白 = 敲这个键掉的就是它（判定，9d 起按「下一个待敲键」匹配——单键星就是那个字母，多键星是键序里进度指向的那一键）；暖橘 = 快落地了（紧迫），白圈优先。白圈永远指向敲了有用的星，还没轮到的后续键不亮圈。**多音字星（9g）有多个待敲键，白圈改成保守口径**：只有当它对**自己每一个**候选键都是最低的那颗、且至少有一个候选键与别的星共享时才亮——「行」（x/h）在上、「好」（h）在下时，敲 h 掉「好」、敲 x 掉「行」，所以「行」不亮（亮起来等于说"敲 h 也掉我"，是撒谎），「好」照旧亮。宁可少亮，不能撒谎。**序列星那排进度点不是第三种描边**：它在星体内部、不脉冲、只随推进亮一格，说的是"敲到第几键"而不是"该敲哪颗星"。
- 剪影类硬边用矢量 Graphics 不烤纹理（烤了被 zoom 放大发糊，超采样又太贵）；软渐变才烤纹理。

## 反馈契约

**一次命中五件同时发生，缺一不可**：放大闪白（炸开不是压扁）/ 星屑带重力飘散 / 白环先白后星色荡开 / 原字母上飘放大 / 飘分上浮（字号随倍率、高倍率转金、贴边翻转不出画布）。**爆开放的是星体拷贝不是真星**——真星立刻归还池，否则还在场上会被再判一次。

**键序推进那一下不是击落**（9d 双星 / 9e 序列星同一条）：只发字母上飘（说明"这个键吃掉了"）+ 星体自己那份进度反馈——双星是首颗变暗 / 连线缩短 / 第二颗放大，序列星是亮一格进度点；五件套留给敲完最后一键那一下。双星敲完时已经敲暗的那一颗跟着一起炸开，"两颗一起消除"才是真的两颗。**上飘的字形分两种**：推进那一下飘**刚被吃掉的那一键**（快照在推进之前取，所以 h-a-o 是一键一个字上飘）；击落那一下飘**显示面**——敲完「好」飘出"好"，不是飘出最后一键"o"。**多音字星（9g）的快照带的是规范读音的键，未必是玩家真敲下的那个**，所以判定层在推进分支用按下的键覆写快照：「行」敲 h 推进就飘"h"，飘"x"等于告诉玩家"你刚才敲的是 x"。击落那一下不受影响（飘的是显示面）。

叠加反馈按需触发，**普通命中不震屏**（三分钟就晕）：

| 事件 | 效果 |
| --- | --- |
| 坠毁 | 震屏 + 地平线闪光（比全屏红闪贴主题）+ 生命星图标炸开、相邻图标抖动 |
| 误敲黑洞 | **全局最重**：向心缩放回弹 + 全屏黑闪 + 吸积盘粒子旋入 + 更重震屏 |
| 冰晶命中 | 全屏冷蓝叠加（含顶条）+ 六角冰晶满屏缓飘，4 秒与减速同起同落（淡入淡出，不瞬灭） |
| 40+ 连击命中 | hit stop 全场凝一下（星星 / 光尾 / 特效一起慢，不只 HUD） |
| 每 500 分 | 顶部星屑雨庆祝，不盖过地平线，同一档不重撒 |
| 最后一条命 | 天空压暗（星与字母仍亮）、地平线辉光常亮、装饰流星停发、**心跳声**（与压暗同一份判据、同一帧现读） |
| 连击跨档 / 断 | combo 升档变色 + 辉光；断连击横抖转红 |

全屏叠加层（黑闪 / 冷蓝 / 压暗）一律 scrim 矩形，**不用 postFX**（WebGL only，Canvas 下毫无反应，两套实现要各验一遍还会长得不一样）。"全屏"包括顶条；尺寸外扩防露白。

## HUD 与局内

- 顶条**实心不透明**（半透明会让下落星透上来糊住读数），透明度落在下沿裙边，星从条下沿滑出不是硬切。SCORE 滚动不跳变、COMBO 每击弹一下、生命是**星形**图标、爬升条分格刻度（距下一级差几击看得见，爬升归零重填不倒流，封顶恒满转金，闯关暗轨禁用态）。
- 左下角常驻准确率与手速。**开发读数只在 `?debug=1` 出现**（7 定案）：帧率 / 池统计 / 判定 / 特效 / 背景 / 氛围 / 可读性读数、档位表与结算页的 GameScene 残留诊断都收在这个开关后（`utils.debugMode()`）；正常游玩左下角只有准确率与手速一行。参考线默认隐藏，`` ` `` 是隐藏快捷键（不再有按钮入口，?debug=1 下随读数默认开）。池 stats() 保留，控制台随时可读。
- 暂停是覆盖层（launch + pause），吃开局快照不读场景实例；暂停期间一切动画与判定冻住，敲键不攒到恢复补判。**失焦自动暂停**（6d）：窗口失焦与切后台两条都收，局内自动进暂停——切标签页回来停在暂停面板，不瞬间掉命；倒计时缓冲期同样暂停（回来接着数）。已在暂停里、结算转场中不重复触发。

## 屏幕动画

- **开场复用玩法视觉语言**：标题四字像流星从右上斜划落（一字一色、拖光尾、落地闪白 + 压扁回弹 + 星屑），玩家看标题的 2 秒就理解玩法。落定后副标题浮起、菜单依次滑入，全程背景不死。同一划落函数复用给 GAME OVER，不复制第二份。
- **菜单**：五档按钮（强调色凉→暖即难度梯度）+ 动作排（模式 / 说明 / 设置 / 最高分），选档即开局；档位行给反应窗口与特殊星清单，底部实时预览参数与字母池（**字母池读当前方案的内容梯度表**，9a 起档位管物理、方案管内容）；各档最高分随行显示（按方案 × 玩法 × 档位读）。设置 / 最高分 / 模式都是场景内模态不是新场景，开着时底下键盘全闸。**单元方案（9e）的预览行读的是字表**：`字表 N · 键序 a–b 键 · 大我一你…`，样本截到 12 个字（`POOL_SAMPLE`）——字表长到 94 个字时整串铺出来 800px+，会捅穿这一行（它左起 x=28，同一高度右边就是键位行），而键序范围才是这一档的真实难度读数。**多音字（9g）不改这一行**：各读音等长，所以"键序 a–b 键"这个范围读数照旧成立。触屏的键位行同样按方案改口（见触屏节）。
- **模式弹层（9b）**：动作排那枚「模式」按钮点开，按钮标签直接写当前选择（"模式：标准 · 闯关"），菜单底部模式行同步写「方案 · 玩法」与爬升参数。弹层里玩法（闯关 / 无尽）与方案各成一节、每行一枚整宽按钮，**方案节由 `SCHEMES` 注册表驱动——加方案 = 添表行，弹层自动多一行**；当前选择把"（当前）"写进文字不只靠高亮（同设置面板纪律），方案行右侧 meta 写内容梯度一句话。键盘 ↑↓ 换行循环、Enter / 空格确认、悬停同步选中行、Esc 关闭；**选完不关弹层**（同设置面板，可连续调），菜单标签 / 池预览 / 各档最高分在底下实时跟着换。**所选玩法 × 方案持久化**（menu 键，Storage.selection / saveSelection 读写并校验回落），刷新保留；回菜单（结算 E / M、暂停放弃、局内 `\`）恢复上次选择，E 额外预选刚玩的那档。菜单快捷键随之收口：M 开模式弹层，原 ←→ 直接换玩法取消（选择只走弹层一条路）。**9e 起注册表里是标准 + 字母 / 数字 / 符号 + 汉字五个方案**：弹层方案节与排行榜页签随注册表自动多行；数字 / 符号专练入门档就能练（档位只提速），方案行 meta 的一句话梯度照读各方案 desc（**meta 控制在 12 个汉字内**——按钮整宽 344、label 与 meta 两头锚定，再长就叠字）。**行距必须真按行数反推**（`min(44, floor(284 / 行数))`，284 = 画布高 600 − 卡片底边余量 8 − 行块起点 212 − 行块之后那三段固定开销 96）：9b 写的"几何按行数推"其实只推了每行的 y、没推行距，四方案时卡片底 572 刚好，加到五行就变成 616 > 600 的画布高，关闭按钮被裁掉且点不到；反推之后四方案（六行）算出的仍是 44，**现有布局逐像素不变**，五方案（七行）40 ⇒ 卡片底 588、关闭按钮 538–578 点得到，七方案（九行）31，行距小于按钮高时按钮高度跟着收（`min(36, step - 6)`）。排行榜页签在五方案时宽 76，四字方案名 13px 约 52px 居中放得下，不必另调。
- **排行榜按方案分栏（9b）**：最高分面板顶部一排方案页签（注册表驱动，默认停在当前方案），←→ 换栏、点选 / 悬停同步（选中项真的换了才响 uiMove），栏内是该方案的「玩法 × 档位」记录表。**跨方案分数不并列比较、不做归一化总榜**——内容不同的方案分数没有可比性。**入榜纪律**：弹层里都是定死规则的方案、都入榜；将来若加方案内自由筛选，属练习配置、不入榜。
- **倒计时**：3-2-1-GO! 与生成器共用一个时钟（字没淡完生成器不许跑）；缓冲期暗遮罩 + 本局信息条（确认自己选了哪档）。
- **结算逐行揭示**：GAME OVER 划落 → 分数滚动 → 七行统计滑入 → 破纪录金横幅 + 星屑雨（或非纪录的最高分行）→ 三按钮淡入，总长 ≤3.5s，揭示完成前键盘与点击全闸。
- **说明页（9e 起五页）**：页码圆点的起点、底部提示的"1–N 直达"与直达键那条正则都按 `STEPS.length` 推——原先三处硬编码写死 4，加一页圆点就偏心、第五页也按不到。**第五页的示意图读与真实星体同一份常量**（星体尺寸 / 面字号 / 面位置 / 点距点径），照双星那页的纪律：示意图与游戏里长得不一样就等于白教；星体用超采样那张纹理显示到 96（其余示意仍是 72 源那张），否则示意图自己就违反只缩不放。**第五页那句补充行多写一句"多音字任一读音都算对"**（9g）：note 带子是 374–424 共 50px、12px 字两行约 30px，两句仍在带子里，不必动版式。示意图不画第二条键序——画两条并行路径会把这一页真正要教的"一个字 = 一串键"讲糊，所以这条规则只能靠文字说。
- 菜单 / 结算的入场部件 create 时就藏好（alpha 0），不是动画开始才藏。

## 声音（6b：全部事件已落地）

Web Audio 现场合成零素材（Phaser 声音管理器已关，AudioSys 是唯一出声口）。**一个事件 = 一份共用参数 + 可选的分层**：琶音 / 心跳 / 黑洞这类"一声里好几层"的，每层只覆写自己要改的（音高、时长、起音偏移）。合成只有三种料——振荡器（可滑音）、白噪声（可低通扫频）、LFO（颤音加在包络那个参数上是相加，包络形状不变）。音高 / 音色 / 时长 / 层数全在 `config.AUDIO`，调音改表。

| 事件 | 什么时候响 | 设计意图 |
| --- | --- | --- |
| hit | 命中普通星、双星第二颗 | **音高随连击上行**：A 大调五声音阶两个八度共十音，第 1 击基音、逐击爬一格、第 10 击起封顶、断连击回基音 |
| gold | 命中金色星 | 琶音（根音 · 大三度 · 五度 · 八度），"这一颗值钱" |
| ice | 命中冰晶星 | 两层颤音：低八度慢颤是"冷"，高八度快颤是"冰凌"，两层颤率不同才不是简单震音 |
| void | 误敲黑洞 | 白噪声被低通从亮扫到闷（吸进去）+ 正弦低频下坠（被带走）。**不用 crash**：坠毁是"星掉下去了"，误敲是"你伸手进了黑洞" |
| crash | 坠毁 | 低频下滑 |
| miss | 按错 | 低音量短音，只说"这一下没吃掉"，不跟命中音抢 |
| arm | 键序推进：双星第一颗 / 序列星每敲对一键 | 短促上挑，"这一键吃掉了，还剩几键"。**不是击落所以音高固定**——跟着连击走就与普通命中听不出分别。事件名 9e 从 `pair` 改成 `arm`（9d 起字段就叫 armSound）：普通 / 金色 / 冰晶三类的推进也走它，双星方案与单元方案永不同屏，复用同一声不会撞 |
| count / go | 倒计时 3-2-1 / GO! | C 大三和弦上行，GO 从最后一格再扫上一个八度，是同一段旋律的收束 |
| title | 标题四字落定 | 一字一音上行（与命中音阶同族），流星划落的听觉那一半 |
| heart | 最后一条命期间 | 每 0.72s 一下 lub-dub 低频双跳，第二下更轻更短 |
| uiMove / uiOn / uiBack | 选中项换 / 确认 / 返回 | 确认是上行两音、返回是下行两音——不看文字也分得出方向；移动那声很轻很短（选中项每换一格就响一次，重了就是噪音） |

**特殊星也吃连击上行**：金色琶音与冰晶颤音的**根音取自命中那张音阶表**，专属的只是叠在上面的音色——"连击越高音越高"是全项目一条规则，不因类型断掉。命中音读**类型表的 `sound` / `armSound` 两个字段**，判定路径不按类型 id 分支：加一类特殊星 = 表里添一行，音效跟着走。**推进音不吃连击上行**（9e）：它是"这一键吃掉了"的确认、不是击落；而且合成引擎的 `glide` 是绝对目标频率，给它挂音阶表后 880→1320 的上挑会在高 step 退化成 1.2×——真要随进度上行得先加一个相对滑音参数，留作 9g 的可选拉伸。

四条纪律：

- **首次用户手势解锁 AudioContext，且手势之前连 ctx 都不建**：刷新后 Boot 自动进菜单、标题那时就落定了，若还没有任何点按，建出来的 ctx 只能是 suspended（音一样放不出，还在控制台留一条自动播放警告），所以那一声静默跳过；点过页面之后再回菜单就听得到。
- **suspended 期间的音直接跳过不排队**（那时 currentTime 不走，排进去的音会在解锁那一刻挤着放）。window 上的解锁监听常驻不摘——iOS 切后台回来 ctx 重新 suspended，下一次点按顺手再解锁。**恢复不靠刷新**（6d）：回前台时若已有过手势就主动 resume 一次（桌面浏览器切后台会自动挂起，回来不必先点一下才出声）；没解锁过的不建 ctx、不伪造手势。iOS 的 interrupted 态（来电 / 切后台）与 suspended 同等对待——凡非 running 非 closed 都 resume。
- **并发上限按"层"算，满了丢最老**（抢掉的那层 8ms 快速淡出防咔哒，连打不糊）。上限从 6a 的 8 放宽到 12：一个事件现在可以是四层琶音，照 8 会在连打时把琶音拦腰丢掉。
- **UI 音只在 `ui.button` 的 activate 一处**：指针点击与键盘（Enter → flash）都经过它，不会各响一次。绕开按钮的快捷键（菜单 T/O/B/M、局内 Esc/`` ` ``/`\`、暂停 Esc/M、说明页 Esc、结算 R/E/M）在自己的 handler 里补**同一份事件名**，否则点击有声、按键没声。选中音只在**选中项真的换了**时响（构造时那次 select、悬停回原项都不响）。翻页音放在 `show()` 里而不是按钮上——六条路径都经过它，一处就够。

设置面板的音量 / 静音**先改再响**，面板于是自己演示自己：按下静音那一声被 muted 直接挡掉（静音了就不该还响一声），解除静音才听得到确认音，音量步进那声轻音就是新音量下的响度。这三个按钮因此都显式不出声（`sound: null`）。

**BGM 不做**（原未决 #2 的定案）：星空 pad 与命中音抢频段，循环调度还要另一套时钟与暂停处理，而"默认关"的选项绝大多数人不会打开——收益不如把这一步花在逐事件音效上。设置面板因此只有 音量 / 静音 / 减少动效 / 严格模式。

## 设置面板（6c）

菜单内模态（不是新场景），五行一列：**静音 / 音量 / 减少动效 / 严格模式 / 关闭**。音量行是「− 读数 +」三件，其余每行一枚整宽按钮，开关状态写进文字（"静音：开"不只靠高亮）。严格模式那行把代价写在标签上（"按错 −10 分"），开之前就知道它干什么。

**键盘全程可达**：↑↓ 换行（循环）、Enter / 空格切换选中行、←→ 步进音量（仅音量行）、M 全局静音、Esc 关闭。指针悬停同步选中行，与主菜单同一条"选中项真的换了才响 uiMove"。音量 / 静音三枚按钮仍是 `sound: null` 先改再响（见声音节）；减少动效 / 严格模式走按钮缺省确认音。

四个开关全部持久化（settings 键，Settings 系统唯一写者），刷新保留；隐私模式降级内存，本会话有效。**严格模式吃开局快照**（入口只在菜单，局中改不了）；**减少动效是触发点现读**，切了立即生效不用重开——菜单里切掉，背景装饰流星当场停发就是看得见的回响。减少动效那行在系统偏好开着时标注"（跟随系统）"，开关状态写的是**生效值**：此时拨到关也仍是开（见无障碍节）。

## 无障碍与降级

- **减少动效**（设置开关 ∨ 系统偏好，6d 已并）：砍**震屏**（坠毁与黑洞误敲两处）/ **hit stop** / **里程碑星屑雨** / **装饰流星**，游戏本体完整可玩，立即生效不重开。生效值 = 设置开关 **或** 系统 `prefers-reduced-motion: reduce`——系统开着时设置拨到关也降，面板那行标注"（跟随系统）"说清为什么关不掉。门控读取口只有一处 `utils.reducedMotion()`，触发点现读；系统偏好那半走 `utils.systemReducedMotion()`（只给面板标注用，门控不直接读它），系统切换立即跟上。老浏览器 / 没有 matchMedia 一律当"系统不减"，只认设置开关。保留的：黑洞误敲的 zoom 回弹（缩放不是震屏）、命中五件套、冷蓝 / 黑闪 / 压暗等 scrim 叠加（颜色变化不是运动）、HUD 滚动与弹跳。已在飞的装饰流星自然飞出画面不瞬灭（与最后一条命停发同一条取舍）。splash 的 CSS 动画由同名媒体查询就地关掉。
- 色觉友好：类型靠形状（见上），不依赖红绿对比。
- **失焦自动暂停**（6d 已落地）：见 HUD 与局内节。
- **AudioContext 挂起恢复不需刷新**（6d 已落地）：见声音节。
- **触屏降级**（6e 已落地）：检测 `navigator.maxTouchPoints > 0` ∨ `'ontouchstart' in window`（`utils.touchDevice()`，缺 API 一律当纯键盘——降级宁可少给不误给；触屏笔记本两个信号都有，键盘与点星并存，降级是加法不是替换）。触屏设备菜单顶部多一条琥珀提示条"本游戏需要键盘 · 触屏降级：点星星 = 敲它的下一个键"（随 revealMenu 淡入），底部键位行换成触屏说明——**提示条恒写"下一个键"，底部键位行才按方案改口**（9e）：星面上没有字母时"敲它的字母"是假话，而 `ui.badge` 的底衬是按建时文本量的、事后改不了字，所以那条必须对两种方案都真（单键星的"下一个键"就是它显示的那个键）；键位行是普通 Text，在 `setLevel` 里按 `level.units` 换。**判定不另开一套**：点中哪颗星就把它**下一个待敲键**喂进与键盘同一份 judge()，最低优先 / 黑洞误敲 / 双星顺序全部原样——点双星还没轮到那颗就是顺序错，点重复字母里偏高那颗掉的仍是最低那颗（白圈说的仍是实话）。点单元星就是敲它进度指向的那一键，统计口径与键盘一致（能不能靠点星星回忆出拼音是另一回事，降级宁可少给不误给）。**多音字星（9g）点它只走规范读音**（字表里那条读音的第一条）：键盘能把两条读音都打出来，触屏做不到——"点一颗星 = 敲它的下一个待敲键"在多读音下没有唯一答案，而一个点只能喂一个键。这是触屏降级又多出来的一条代价，记在案。点空白不计失误（没有字母可判，与键盘"非池键忽略"同义）；装饰流星不在判定候选里，天然点不动。热区半径是 config 值（TAP_RADIUS，世界坐标），手机 FIT 缩放后仍有指腹量级，重叠候选按最近圆心消歧；**地平线以下的点击一律忽略**——那是暂停 / 回菜单按钮的地盘（按钮在 pointerup 激活、点星在 pointerdown 判定，不隔开的话点暂停会顺手判掉一颗星）。暂停 / 回菜单 / 设置 / 说明翻页 / 结算三出口本就有指针按钮，触屏全程可达；AudioContext 解锁复用 main.js 常驻的 pointerdown 监听，第一次点星就出声。canvas 加 `touch-action: manipulation` 关掉双击缩放，连点不触发页面缩放。
