# 玩法规则

> 需求的内容细节：玩什么、怎么判定、怎么算分、玩家看到什么。不谈实现。核心一句：**阶梯式广度复现——呈现 → 隐藏 → 按序复现 → 全对长度 +1 → 出错即终，得分 = 最大全对长度。玩法不创新，力气押在手机手感。**

## 核心循环

- 长度是唯一关卡变量：起始 2（休闲可在设置页调 2–4，冲榜与挑战锁 2，见设置项），每全对一关 +1，无上限。得分 = 本局最大全对长度。
- 单局短（打到长度 8 约 2–3 分钟），随时来一把。

## 四种类型

| 类型 | 符号集 | 呈现 | 记忆通道 | 复现输入 | 定位 |
|---|---|---|---|---|---|
| 颜色 | 4 色各配固定形状 | 中央逐个闪现 | 视觉（可选听觉） | 点 4 色块（四象限） | 入门热身 |
| 位置 | 3×3 九宫格 | 棋盘上点亮格子 | 视空间 | 按序点格 | 最纯广度测量 |
| 数字 | 0–9 | 中央逐个闪现 | 语音回路 | 点 0–9 电话键盘 | 记录主项目 |
| 扑克 | 52 张 | 中央逐张翻出 | 语义编码 | 先选花色再选点数，选过置灰 | 进阶，测方法 |

**呈现形态判据（核心不变量）**：看呈现时哪个维度在变——位置变而身份不变测空间，身份变而位置恒定测身份。**呈现与复现共用棋盘时位置是身份的免费索引**，四类型会塌成同一款空间广度游戏。所以除位置外一律中央呈现：**呈现不泄露位置，复现棋盘才有意义。** 位置类型的内容就是位置本身，搬到中央就没内容了。形态只动呈现层，序列仍是符号下标数组，判定/计分/存档不变。

- **类型间分数不互比**（通道差异不是能力差异），记录/曲线一律按类型分组。
- 符号集越小越测原始广度（约 4 组块），越大越测策略训练水平。颜色 25% 蒙对率、数字 10% 蒙对率是认下的代价。
- **扑克序列无放回**（一关至多一次，长度 52 封顶）：这是"选过置灰不可再选"的前提，允许重复则关卡无解。另三类允许相邻重复（靠项间间隔区分）。

### 颜色的冗余通道与音调

- 每色块配固定形状（圆/方/三角/菱），呈现与复现两端常驻，是色盲玩家**唯一**非颜色通道。选色避开红/绿对。
- 中央呈现后"位置"冗余在呈现端消失，**不做位置标记**；形状本来就是常驻的，所以**也不设色盲开关**——开关打开后画面没有可见变化，比没有开关更糟（4b 定案，理由见 requirements.md）。
- 音调开关默认关（首次出声体验差），玩法不依赖它；它开第二条语音回路 + 节奏感，位置冗余没了后价值上升。4a 起可开关、本地记住：开后颜色类型的呈现亮起与点对都按色定音高（四固定音高），打开开关当场预览四音。

## 模式

| 模式 | 生成 | 定位 |
|---|---|---|
| 休闲（累积追加） | 每轮重播整段旧序列 + 末尾新增 1 项 | 默认/亲子/热身；重播允许复述，分数随练习膨胀 |
| 冲榜（每关独立） | 每轮全新随机序列，长度 = 关卡 | 记录与排行唯一来源；得分即真实广度 |

休闲成绩也存但单独一栏不混排行（记录页里它在分隔线下面，不参与冲榜档的 tie-break 顺序，5b）。

**休闲里程碑提速**：**当前序列长度**到 5 / 9 / 13 各提一档，不是"本局累计呈现项数"——按累计项数算，第 2 关就到 5、第 3 关到 9，几乎开局就顶满，里程碑失去意义。**只有休闲有里程碑**：冲榜与挑战局内不提速，开局那一档就是全程那一档（3c 起明确，此前冲榜局内也会跟着提速，与这条不符）。提速走**自己的台阶**（每跨一个里程碑 show / gap 各乘一个比例，下限是可调区间的最小值），**不占 SPEEDS 的档、不进组合键**：SPEEDS 只有 慢 / 默认 / 快 三档而开局是默认，往上只剩一格，装不下三个里程碑；组合键记的是**开局选的那一档**，局内提速不进键，所以按比例走不违背"速度离散不连续"（那条的理由是连续值会把组合键碎掉）。比例与里程碑数值以 `config.js` 为准。

提速必须**被看见**：HUD 的速度读数跟着变小、跨档那一关的短提示说一次"提速"、配一个上行音。玩家不知道为什么画面突然变快，就等于没做。

## 难度

长度是主旋钮，其余是修饰符，不同时拧。呈现速度默认每项 700ms + 间隔 300ms，离散三档，不进设置页；**速度由玩法档决定，不是自由选项**——休闲与冲榜锁默认档（冲榜锁它是为了记录可比，休闲锁它是为了让"提速一档"只由里程碑推进，可选起点会让"从哪一档起算"变成 3×3 的验收面），挑战自带快档。复现方向正/倒序，倒序独立记录（广度平均低约 1 项）。

**倒序（3c 定案）**：呈现仍正序，复现从最后一项点起——反的是判定侧的期望顺序，生成 / 呈现 / 计分 / 存档 schema 一个字段不变。倒序只通过挑战档提供，**不进休闲**（亲子/热身定位与"倒着点回来"天然冲突，里程碑提速再叠倒序更狠）。即点即判同样适用：第一下该点呈现的最后一项，点呈现的第一项就是错在第 1 位。

**阶梯定位表（首页玩法档的来源）**：入门（颜色或位置 默认）/ 标准（数字或位置 默认）/ 进阶（扑克 默认）/ 挑战（任意类型 冲榜 · 倒序 · 快）。**原先排最前的"教学关（颜色 2→4 慢速）"一档已随 7 改判取消**——规则长解释归静态"玩法"页，不做可玩脚本关，所以这一档不进 PRESETS（代码里从来没有它，改判不动代码）。**挑战的快档与"冲榜锁速度"不冲突（3c 拍板）**：组合键本来就含速度档，可比从来都是同组合内可比，挑战记录只跟挑战比；锁速纪律只约束冲榜本档。此前快档在玩家链路不可达，3c 起解决。

常模基线：数字正序 ≈7 倒序 ≈5（均值是"7 ± 2"那个传统读数，**离散度文献没直接给，按公开样本常见的 1.5 取近似**）；eCorsi 正序 6.11±0.80 倒序 5.29±1.20。**扑克与颜色无常模**，只跟自己比。**常模是听觉呈现、本作是视觉呈现，百分位只能近似且页面必须标注。**

**百分位换算（5d，#5 定案）**：正态 z 分数 → 百分位，两端夹在第 1 / 99（说"第 100 百分位"等于说比所有人都强，这份近似数据撑不起那句话）。**三笔账认下、不另做映射**：① **天花板效应**——常模测的是单次广度，本作测的是"打到打不动为止"，高分段一律压在第 99；② **挑战档是快档**——呈现比常模快，百分位偏保守（低估玩家），低估是措辞红线要的那一侧；③ **记录页按最好一局算**——比常模的单次成绩偏高，所以那句话写在页脚而不是省掉。**sd 缺失就是"这一格没有常模"**（不给百分位，也不编一个数）。

**参照只给冲榜档**：休闲是累积追加、重播允许复述，分数不是广度测量，拿去查常模会把练习效应说成能力——与"休闲单独一栏不混排行"同一条纪律。休闲、扑克、颜色一律落回**"历史第几好"**（这一局在该组合最近 20 局里排第几，并列取较好名次；不足两局不给，只有一局时"第 1 好"不是信息）。

## 判定

四类型、两模式、两方向同一条判定路径（数字改点按后"打字 vs 点按"分野消失，**点错就是记错**；倒序只反转期望顺序，判定节奏不变）：**即点即判，点错立刻结束**，不可撤销、没有容错重试——本局结束，分数 = 上一关长度。错了再来一局就好，不必在同一局上死磕（退格 / 整条判定 / 容错评估过不做，见 requirements 3b；以后真有诉求再开阶段）。

- **扑克两步选牌：花色是导航不是提交**（点花色只切面板、不计判定、点错无代价），点点数格才提交才即点即判。两步目标都 ≥44px，手滑不是借口。
- 不限时（手速不污染记忆分数）。

## 计分与记录

得分 = 最大全对长度。tie-break：总错次少 → 平均复现用时短。每份记录带完整组合键 **类型 × 模式 × 方向 × 速度档**（不同组合不可比）→ 历史最大长度、达成日期、最近 20 局曲线、总错次。**记录页 = 本地榜：按类型分页，每组合一张卡**（5b 落地），点一张卡看它最近 20 局曲线 + 历史最高参考线（5c），**常模百分位挂在冲榜档那张卡的第二行末尾**（5d）。

- **只有走完结算的局进记录**：暂停里"回首页"是放弃本局，不记录——放弃不是成绩，混进曲线会把练习效应画成退步。
- **常模参照只给冲榜档，休闲 / 扑克 / 颜色在记录页整行不画**（5d）：休闲的分数与常模不同量纲（见难度节）；扑克与颜色没有常模，而卡上的数字是"最高"——**最高在自己的历史里恒为第 1 好**，"历史第几好"在记录页没有信息量（它只在结算说得出口，那里说的是这一局）。所以记录页的常模句最多出现在两页（数字 / 位置）× 两张卡（冲榜 / 挑战）上。
- **百分位查的是"一个分数"，不是平均分**（5d）：结算查这一局（单次 vs 单次，量纲对得上），记录页查最好一局（偏高，页脚标注）。两条都不做跨类型 / 跨档位的归一化总榜——不同组合不可比这条纪律不因常模而松动。
- **曲线一次只画一个组合**（5c）：不同组合不可比，所以不在同屏并排三条——记录页点哪一张卡就画哪一档的曲线，默认是下一局要玩的那一档。横轴是固定的 20 个槽位（不满 20 局往右长、满了每来一局整条左移一格），纵轴 0 起，历史最高画成虚线参考线。曲线一律标"**本游戏成绩**"（措辞红线，标注长在图的标题上，不只长在页脚）。
- **tie-break 排的是组合，不是局**（5b 定案）：同一类型下的冲榜档之间比——最高长度 desc → 总错次 asc → 平均复现用时 asc，三者全同回落玩法档原序（顺序必须确定，不许随读盘抖）。**局级不排**：即点即判下每局恰好错一次终局，一局的总错次恒为 1，第一顺位在局级是死键；所以这三项只按组合累计存一份，不给每局各存一份（存档 schema 不为此扩容）。休闲档不参与这个顺序（见下条"单独一栏"）。
- **总错次按组合累计**：即点即判下每局恰好错一次终局，所以总错次 = 该组合的终局局数；tie-break 里"总错次少"说的是达到同一最高长度用的失败次数少。
- **平均复现用时 = 累计复现输入时间 ÷ 累计输入数**（5a 起随局记录）：只计复现阶段且判定未定的时间——暂停冻住、全对 / 点错之后等玩家点按钮的等待不计。手速不污染记忆分数（不限时），但同分之下复现快的是 tie-break 的第二顺位。

## 反馈

**结算不是"你错了"，是"你差在哪"。** 依次给：① 最大长度大字滚动；② **逐位对照**（正确 vs 输入并排，三态对/错/错处之后未输入一眼可分——把"没点到"画成"点错了"会冤枉玩家，最易做反）；③ 同组合历史最高，破纪录庆祝；④ **参照一行**（5d）：冲榜档的 数字 / 位置 给常模百分位，其余（休闲 / 扑克 / 颜色）给"这一局在最近 N 局里排第 K 好"——**破纪录时不重复那句"第 1 好"**（新纪录徽标与历史最高那行已经说完了），0 分局两种都不给（没有成绩可比）；⑤ 两出口：再来一局（同设置）/ 换个玩法（回首页带回组合）。**最近 20 局曲线不在结算**（5c 定案）：它是按组合看的历史，归记录页那张选中的卡；结算在 1m 之后是"大字 + 逐位对照 + 诊断一行"那一屏，再塞一块图会把横屏回放的高度预算吃光。**原先排在两出口之前的"技巧提示"一格随技巧库删除**，结算不再留这一格，也不写"敬请期待"。

过程小反馈：呈现每项有视听标记 + 短音；复现显示"已输入 n/m"进度点**不给内容提示**；**扑克另给已选序列条**（玩家自己的输入不是答案，让"选过不可再选"看得见）；全对短促正反馈不拖节奏；**点错那一下要重**（闪光 + 屏震 + hit stop）。

## 屏幕与流程

首页（玩法档 + 四类型 + 记录 + 设置 + 玩法）→ 点类型直接开局 → 局内循环 → 结算（再来一局 / 换个玩法）。

- **"玩法"是常驻入口不是首次拦截**（7 改判）：规则长解释全在这一页，局内短提示与结算都不重复；不做可玩脚本关（规则五句，三段相位自己在教），是否首次自动打开一次由人点决定，真要也只是一个本地布尔。

- **没有独立选设置屏**：开局前选择压成首页两层——玩法档（模式×方向×速度的命名组合，一行胶囊，只一个档时整行不画；休闲落地后是 休闲 / 冲榜 两个，默认档排最左）+ 类型（主菜单四行，点即开局）。**没开放的档不画不置灰**，玩家看到的永远是现在能玩什么。
- 局内任何时刻可唤出**暂停**（覆盖层非独立屏：继续/重开本局/回首页）。**呈现阶段暂停要把序列一起遮住**。不限时，暂停不影响可比性。
- 三条呈现规则：① 三段视觉区分明确，呈现全屏给序列不给操作入口，隐藏后才出输入界面，中间留玩家自己点的"开始复现"不用倒计时催促；**中央呈现三类呈现期连复现棋盘都不露**。② 局内常驻 HUD（类型·模式·长度·进度点），读开局快照不回读设置。③ 手机竖屏主力，横屏是同构件换排布不是第二套设计；**转屏/尺寸变化不丢当前局**。

## 设置项（两层）

- **玩法档**（首页胶囊）：模式、方向、呈现速度——都进组合键，是"玩什么"。
- **全局偏好**（设置页）：通用音效开关、颜色音调开关（默认关）、起始长度、进度点显示开关——不影响可比性，跨组合生效。**四项 4c 全部落地**：本地持久化（systems/Prefs）、开局由 Setup.snapshot 读进快照、局内改不了（纪律 1），入口在设置页（4a 曾暂住首页，4c 整块搬走）。
  - **起始长度**：离散三档 2 / 3 / 4（config.START_LENGTHS），默认 2，**仅休闲生效**；冲榜与挑战锁 2（否则记录不可比），锁定在 snapshot 一处做，不在生成器里认模式。上限低于第一个里程碑 5：起始 ≥5 会让开局第一关就跨档提速，"提速必须被看见"在开局那一关失效（没有"变快之前"可比）。起始长度**不进组合键**——休闲成绩单独一栏不混排行，可调不产生不可比问题（未决 #2 就此定案）。
  - **进度点显示**：关时只砍 HUD 的圆点，"已输入 n/m"计数保留（文字读数不是点）；点错的红点随之消失，错处由底部"错在第 x 位"与危险色 / 抖动 / 低鸣表达，信息一条不丢。
  - **色盲模式不在这一层**（4b：非颜色通道常驻，没有可切的东西）；**减少动效也不在**（跟随系统 `prefers-reduced-motion`，是系统偏好不是玩家偏好）。

两个玩法档都锁默认速度（休闲的提速只由里程碑推进）；符号集一律锁死（不缩小扑克候选集）。

## 措辞红线

- 不写"提升记忆力/变聪明/过目不忘/预防痴呆/延缓认知衰退"（Lumosity FTC 案：宣称超出自有证据）。
- 不给 IQ、脑龄、医学诊断。
- 曲线一律标"本游戏成绩"；分数上涨是练习效应、4–8 周平台期是常态，这句实话写记录页脚。
- **百分位一律带近似标注**（5d）：常模多为听觉呈现、本作是视觉呈现，那句差别与"只是近似参照、不是测量结论"必须与百分位同屏；记录页还要多说一句"按你最好的一局算，偏高"。窄列可以换短版，**不能整句砍掉**——砍掉标注的百分位就变成了一句结论。
- 方法类文案（若给）只写"方法是什么、怎么用"，不写"用了能记住多少"——技巧库整页不做（见末节），这条管的是首页类型行那种随手写的几句。
- 卖点四条：**免费、无广告、无需注册、进度本地保存**。**"离线可玩"不许写**（Phaser CDN），9 的 SW 缓存引擎后才能改"首次加载需联网，之后可离线"。

## 明确不做

## 技巧库：不做（原"整段延后为后续 Feature"已收口）

评估后删除，不是延后（requirements 6 行记理由）。要付的成本是四类型 × 三层共 12 条手写内容 + 一个库页 + 结算按该类型历史最大长度选层的触发逻辑（≤3 不推 / 4–5 推 L1 / 6–7 推 L2 / 8+ 推 L3），**换来的是零逻辑零测试价值的纯内容页**；而措辞红线又禁掉了唯一有说服力的话术（"用了能记住多少"），剩下能写的只有"方法是什么、怎么用"——那用不着一个库页，也不值得为它建一套触发与已读状态。

**认下的代价**：中央呈现后扑克少了位置这条免费索引，没有编码技巧（牌面 → 形象 / PAO）会早触顶在 4–5。但触顶不污染任何数据——记录按组合分开，扑克照样可玩、可比、可练。原设计写的"技巧库落地前扑克是半成品"这句过重，**撤回**。

**替代**：真要给方法，首页四行类型各带一句（扑克如"先给每张牌编个形象，再记形象"），四句文案随手做，不单列阶段、不建库页、不做触发。原三层阶梯表（颜色节奏化 / 分组 / 语义化画面，位置路径化 / 形状化 / 宫殿法，数字 chunking / 谐音挂钩 / major system，扑克牌面→形象 / PAO / 宫殿串联）已从本文档删除，真要用去 git 历史里取。
